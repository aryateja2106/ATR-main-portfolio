# Creator Onboarding Kit

This kit is for a one-week contractor creating and posting content for Arya Teja Rudraraju.

Use it in this order:

1. [AGENT-CONTEXT.md](./AGENT-CONTEXT.md) - source hierarchy, proof rules, prompts, and unknowns.
2. [BRAND-GUIDELINES.md](./BRAND-GUIDELINES.md) - voice, positioning, visual rules, CTAs, and proof boundaries.
3. [ICP.md](./ICP.md) - who the content is for and what they need to trust.
4. [CONTENT-PLAYBOOK.md](./CONTENT-PLAYBOOK.md) - daily workflow, platform rules, checklist, topics, and naming.
5. [index.html](./index.html) - local browser summary of the kit.

Long-form article template: `apps/web/content/blogs/ARTICLE-TEMPLATE.md`.

## Week Goal

Create practical, sourced content that helps qualified founders, operators, small teams, collaborators, and builders understand Arya's work in secure AI agent systems, local-first workflows, remote agent access, workflow audits, and business-first AI implementation.

## Non-Negotiables

- Do not invent facts, metrics, testimonials, product status, release dates, security claims, or client outcomes.
- Mark missing information as `TODO:`.
- Do not publish secrets, private URLs, credentials, active pairing links, private client details, or private SecondBrain content.
- Do not position Arya as an AI Product Manager, job seeker, aspiring candidate, Dallas-based operator, or crypto/blockchain consultant.
- Do not use em dashes in public copy.
- Keep claims tied to sources, screenshots, repos, demos, published pages, or Arya's explicit review.

## One-Week Output Target

- 5 daily content packages.
- Each package includes one canonical note, one LinkedIn draft, one X draft or thread, one visual brief, source links, and a review checklist.
- Publish only after Arya approves the final copy and proof links.
