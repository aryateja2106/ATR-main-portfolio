# ICP

## Primary Audience

Warm US connections, founders, operators, and small teams exploring practical AI agent systems.

They need to answer:

- Can Arya understand a real business problem?
- Can he work remotely from India?
- Can he ship a secure, useful system?
- Can he explain tradeoffs without overselling AI?

## Secondary Audience

- Collaborators.
- Open-source builders.
- Recruiters.
- Search engines.
- Software agents reading the site and public metadata.

## High-Fit Problems

- "We want to use coding agents, but need safe setup and review boundaries."
- "We have manual workflows and need to know which AI automations are worth building."
- "We need local-first or private workflows because data control matters."
- "We need remote access or mobile supervision for long-running agent work."
- "We want a technical founder who can prototype, audit, and explain the system."

## Content That Works

- Build logs from actual projects.
- One decision, one tradeoff, one thing that broke.
- Practical guides with commands, screenshots, and verification steps.
- Open-source breakdowns with what to copy and what to avoid.
- Security and trust posts that explain boundaries.
- Business-first AI posts that start with the workflow, not the model.

## Content That Does Not Fit

- Generic AI news commentary.
- Crypto or blockchain positioning for CloudAGI.
- Stale Dallas or AI Product Manager positioning.
- Job-search content.
- Unsupported claims about user counts, revenue, interviews, or production status.
- Personal biography without an artifact, source, or lesson.
