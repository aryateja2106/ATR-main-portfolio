# Toolkit Map

## Impeccable

Use for design vocabulary, anti-pattern detection, audits, polish, hardening, typography, layout, and final visual QA. Installed repo-locally at `.agents/skills/impeccable`.

Good default:

```bash
npx impeccable detect apps/web
```

Use the `$impeccable` skill when working inside Codex.

## Open Design

Use as an external workbench or reference library for prototypes, social carousels, posters, shortform video briefs, decks, and design systems. Do not copy its raw skills into this repo unless the task explicitly sets up Open Design runtime.

Useful reference skill categories:

- `social-carousel`
- `image-poster`
- `video-shortform`
- `blog-post`
- `html-ppt-tech-sharing`
- `social-media-matrix-tracker-template`

## Beautiful HTML Templates

Use as deck inspiration, not website runtime. Strong candidates for Arya:

- `8-bit-orbit`: retro terminal and hacker energy.
- `bold-poster`: strong manifesto cards.
- `cobalt-grid`: technical diagrams and build notes.
- `neo-grid-bold`: punchy open-source breakdowns.
- `signal`: quieter institutional trust.
- `studio`: high-contrast launch visuals.

## Career-Ops

Use as an operating-model reference for structured evaluation, proof points, trackers, and story banks. Do not install into this repo unless Arya asks to create a job-search workspace.

Borrow these ideas:

- Scored evaluation rubrics.
- Proof-point bank.
- Batch processing.
- Tracker integrity checks.
- Human final decision.

## Browser Harness

Use only when real browser/profile control is needed. Prefer isolated browser profiles for risky automation. Do not wire it into this repo by default.

## Noustiny

Use as a reference for narrative branching, continuity, IP scrubbing, and render chains. Do not reuse code or assets unless licensing is clarified.

## Canva

Use for production social templates once the Canva plugin or connector is active. Keep source copy and visual briefs in this repo so assets remain reproducible across agents.
