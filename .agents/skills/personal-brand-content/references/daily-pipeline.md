# Daily Pipeline

Use this for a one-hour daily content block.

## 60-minute flow

1. 0 to 10 minutes: choose one source and define the claim.
2. 10 to 20 minutes: verify facts and capture source links.
3. 20 to 35 minutes: write the canonical note.
4. 35 to 45 minutes: adapt to LinkedIn, X, and YouTube Shorts.
5. 45 to 55 minutes: write the visual brief or capture the screenshot.
6. 55 to 60 minutes: voice check, publish checklist, archive.

## Daily package checklist

- One core idea.
- One verified source or personal build artifact.
- One builder takeaway.
- LinkedIn version.
- X version.
- YouTube Short script.
- Visual brief.
- Source links.
- One follow-up idea for tomorrow.

## Archive fields

- Date.
- Topic.
- Pillar.
- Source links.
- Draft copy.
- Final copy.
- Visual brief or asset path.
- Published URLs.
- Reflection: what got easier, what felt blocked.
