# Editorial Pillars

## Pillar 1: Agentic engineering in public

Write from the build floor. Share what changed in LeCoder MConnect, CloudAGI, LeSearch AI, NL2Shell, or the website. The best posts show one decision, one tradeoff, or one thing that broke.

Prompt:

> What did I build, test, remove, or finally understand today?

## Pillar 2: Multi-agent orchestration

Focus on coordination surfaces: plans, PRDs, subagents, repo state, MCP minimalism, browser control, tool permissions, remote sessions, and handoffs.

Prompt:

> What do agents need to know, verify, or avoid before they can act safely?

## Pillar 3: Remote machines from mobile

Teach the mobile control layer: SSH, VNC, tunnels, browser automation, terminal state, approvals, screenshots, and real device constraints.

Prompt:

> What becomes possible when the phone is not just a viewer, but a control surface?

## Pillar 4: Open-source field notes

Break down one repo, tool, or pattern. Make it practical: what it does, why it matters, what to copy, what to avoid, and who should study it.

Prompt:

> What did this repo teach me that another builder can use this week?

## Pillar 5: Security and self-hosting

Write about secrets, local-first tooling, browser profiles, remote debugging, agent permissions, RLS, production safety, and trust through inspection.

Prompt:

> What should a careful builder verify before letting an agent touch this?

## Pillar 6: Builder biography

Use the honest arc: long-time AI enthusiast, now building real products and learning in public. This is strongest when anchored in an artifact, not just reflection.

Prompt:

> What assumption changed once I actually built the thing?
